# 電子商務與數位行銷企劃：ReLens 底片相機租借與沖印平台

本專案為大學「電子商務」課程期末團隊專題，聚焦於底片相機租借、底片加購與沖印掃描流程的整合構想，並搭配網站展示與數位行銷企劃規劃。

## 1. 專案背景與想解決的問題
傳統底片攝影在租借或購買器材、挑選底片、後續沖洗與取得數位檔的流程上較為零散，對新手或只想在旅遊、聚會偶爾體驗底片質感的使用者而言，初期門檻與成本較高。本專題發想以「一站式租借與沖印服務」為核心，降低體驗門檻並串聯線上預約與線下寄回沖洗流程。

## 2. 與「行銷與數位分析」的關聯
- **目標客群與市場切角**：分析底片美學愛好者、旅遊／派對等情境式使用者，以及偏好儀式感體驗的族群，並估算潛在市場規模。
- **數位行銷與導流構想**：規劃社群內容經營、SEO 關鍵字方向、檔期廣告與再行銷想法，思考如何從線上吸引受眾、引導下單，並透過沖洗後數位照片回傳促使使用者再次分享。
- **網站介面與使用者體驗（UX）**：觀察商品分類、租借天數與費用說明、購物車與結帳流程，以及行動版響應式呈現（RWD）對瀏覽與下單體驗的影響。

## 3. 使用工具與課程實作內容
- **企劃與視覺簡報**：簡報架構規劃、商業模式與行銷策略整理、復古風格視覺排版
- **網站建置與後台操作**：使用 WordPress 建置網站架構與商品／租借頁面，並搭配 Google Analytics 理解網站流量與使用者行為概念；我本人亦曾參與後台操作，後續因電腦設備無法順利運行，轉由同組負責網站架設的組員接續完成後續操作與部署。
- **實作挑戰與反思**：團隊在 WordPress 設定、資料庫／主機部署、部分頁面與網址顯示，以及裝置環境相容性上遇到實務困難，透過向助教請教、查詢資料、運用 AI 輔助排查與反覆測試逐步解決，也體會到團隊分工與即時支援的重要性。
